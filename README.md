# Web 1.0: каким был интернет?

Интерактивная сайт-презентация о раннем интернете. Статика (HTML + CSS + JS), без сборки и backend, все пути относительные: готово для GitHub Pages.

## Как открыть

Двойной щелчок по `index.html` работает. Для проверки «как на хостинге»:

```bash
python -m http.server 4180
```

и открыть `http://localhost:4180/`.

## Публикация на GitHub Pages

1. Залить содержимое папки в ветку `main` репозитория `chikirao/web_1_0_story`.
2. **Settings → Pages → Deploy from a branch → main / (root)**.
3. Сайт будет по адресу `https://chikirao.github.io/web_1_0_story/`.

Инструкция для поддомена `web1.chikirao.ru`: [docs/DOMAIN.md](docs/DOMAIN.md).

## Главная и режим презентации

- **Главная** остаётся «личным сайтом в окне браузера»: меню, панели, кнопки 88×31.
- **Главы** (`slides/`) открываются в режиме презентации: окно браузера развёрнуто на весь экран,
  меню «Файл, Правка…» убрано, тулбар низкий, адресная строка и панель глав остаются.
  Всё место отдано слайду с крупным текстом.
- При переходе с главной окно анимированно разворачивается, при возврате на главную сворачивается обратно.
- Слайд правится внутри `<main class="slide">`: заголовок, `.slide__body` (текст + картинка), кнопки внизу.
- Длинный слайд с секциями: `<main class="slide slide--long">` (так сделаны 01 «Подключение», 02 «Дизайн» и 03 «Поиск»). Интерактив слайдов лежит в `assets/js/` (`connection.js`, `design.js`, `search.js`).
- Слайды, сделанные вручную, помечены комментарием `handmade`: `make_slides.py --force` их не перезаписывает.

## Мобильная версия и проверка

На экранах до 900 px главы прокручиваются целиком. Реплики Чикиряо находятся
над содержимым: кнопка «Чикиряо: читать реплики» раскрывает их, а «Свернуть реплики»
освобождает место. Состояние сохраняется между главами отдельно от версии для ПК.
Схема звонка вертикальная, широкие таблицы прокручиваются внутри своих окон.
В машине времени кнопка «Читать крупнее» открывает страницу в исходном масштабе
с прокруткой, «Показать целиком» возвращает общий вид.

Автоматическая проверка в headless Edge:

```bash
python -m pip install playwright
python -X utf8 tools/check_responsive.py
```

Скрипт сам запускает временный локальный сервер, проверяет все шесть страниц
на телефонах, планшетах и ПК, а также плеер, словарь, машину времени, CRT,
реплики и переходы. Скриншоты сохраняются в `.local-check/`, эта папка игнорируется Git.
Для MP3 сервер поддерживает Range, как GitHub Pages: обычный `http.server`
не позволяет Edge правильно перематывать запись.

## Рассказчик Чикиряо

Чикиряо живёт поверх всей страницы (справа снизу), не влияет на вёрстку и высоту страницы.
Это текстовая версия того, что говорит докладчик.

- **Реплики** каждой страницы лежат в её HTML, в списке `<ol class="narration">` внизу файла. Одна `<li>` = одна реплика. У последней можно задать подпись кнопки перехода: `data-next-label="Поехали!"`.
- «Далее» на последней реплике ведёт на следующую главу, «Назад» на первой ведёт на последнюю реплику предыдущей.
- Клавиши: **→ / PageDown** дальше, **← / PageUp** назад. Пульт-кликер для презентаций тоже работает.
- Клик по Чикиряо: машет лапами. Перетаскивание: поворачивается в сторону движения (2.5D), болтает ногами. Двойной клик: вернуть на место. Позиция запоминается между страницами.
- **Если сильно потрясти и отпустить**, у него кружится голова: голова смотрит в разные стороны, лапки крутятся, вокруг летают звёздочки, потом он падает на бок и встаёт. Порог тряски и длительность фаз: `SHAKE_*` и `DIZZY` в разделе 6 `script.js`.
- Реплики печатаются посимвольно (скорость `TYPE_CPS` в разделе 5 `script.js`), облачко растёт вверх, кнопки «Назад/Далее» остаются на месте. Клик по тексту допечатывает сразу.
- Кнопка «×» прячет облачко, клик по Чикиряо возвращает.
- Любой элемент с `data-bunny-say="…"` заставит Чикиряо сказать фразу (так сделаны шутки в меню браузера).

### Панель настроек ⚙ (для разработки)

Кнопка справа сверху. Сейчас там подстройка головы по 24 ракурсам:

1. Выбрать ракурс в сетке (ряд = высота камеры, число = поворот), он зафиксируется на экране.
2. Ползунками поправить высоту и сдвиг головы. Правки сразу сохраняются в этом браузере.
3. **Экспорт → буфер**, вставить целиком в `assets/bunny/bunny-tuning.js`: правки попадут на сайт для всех.

Перед защитой кнопку можно выключить: в `script.js` поставить `SITE.devTools = false` (временно включить: открыть страницу с `?dev`).

### Пересобрать Чикиряо из игры

```bash
python tools/build_bunny.py D:/dev/katamari_web
```

Скрипт повторяет сборку из `src/rabbit.ts` игры (атласы головы и тела, калибровка `rabbit-user-settings.json`, исправленные головы 135°). Для вида спереди голова садится на горловину тела: параметр `OVERLAP` в начале скрипта.

## Счётчик посетителей

GitHub Pages отдаёт только статику, поэтому настоящий счётчик ведёт внешний сервис
[GoatCounter](https://www.goatcounter.com/) (бесплатно для некоммерческих сайтов, без cookie).
Он отличает посетителей по IP + браузеру (обезличенный хэш), так что перезагрузка страницы не накручивает число.

1. Зарегистрироваться на goatcounter.com и создать сайт с кодом, например `web10` (адрес будет `web10.goatcounter.com`).
2. В настройках сайта GoatCounter включить **«Allow adding visitor counts on your website»**.
3. В `script.js` вписать код: `SITE.goatcounter = "web10"` (сейчас вписан `"chikirao"`).

После этого каждая страница отправляет просмотр, а счётчик на главной показывает общее число посетителей.
Сервис обновляет итог с задержкой (до 4 часов) и не считает заходы с `localhost`.
Пока код не вписан, счётчик локальный (считает визиты этого браузера).
`SITE.counterStart` прибавляет число к показанному, если хочется «старый сайт с историей».

## Как добавить главу

1. Главы перечислены в массиве `CHAPTERS` в начале `script.js`: по нему работают «Назад/Вперёд», адресная строка и переходы рассказчика.
2. Каждая глава это файл в `slides/`. Удобнее всего править готовую заготовку: заменить содержимое `<main class="slide">` и реплики в `<ol class="narration">`.
3. Для новой страницы: `python tools/make_slides.py` (существующие файлы не трогает; `--force` перезаписывает все).
4. В `slides/` все пути начинаются с `../`, а у `<body>` стоят `class="page-chapter"`, `data-root="../"` и `data-chapter="N"`.

## Звук модема (по желанию)

Положить файл, например `assets/audio/dialup.mp3`, и указать путь в `script.js` → `SITE.dialupSound`. Звук играет только после клика «Начать путешествие», без автозапуска.
